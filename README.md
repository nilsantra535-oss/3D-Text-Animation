# 3D Text Animation 

A creative, purely CSS and HTML-based 3D text rotation animation project featuring a dynamic wave/cylinder rotating effect centered around the text **"NILANJAN"**.

## 🚀 Features
- **Pure HTML & CSS:** No JavaScript required for the animation.
- **3D Transform Effects:** Uses `preserve-3d`, `perspective`, and `rotateX` to create an immersive depth effect.
- **Custom Fonts:** Integrated with Google Fonts (**Poppins**).
- **Smooth Infinite Loop:** Continuous 360-degree rotation animation.
